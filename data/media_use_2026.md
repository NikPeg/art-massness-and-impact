Survey values, not a census of all humans. Comparison A uses primary work formats; these broad source categories are imperfect proxies and have not been recoded item by item. Comparison B, media components across all formats, is recorded separately in [the component inventory](media_components_2026.md).

Other source categories: all TV, including streaming, has 86.1% weekly reach and 598 weekly minutes. These aggregates are not additional disjoint media categories. The game-frequency values overlap and must not be added. The long-online-video row is an explicit proxy, not a disjoint audience. The linked report also gives 3.36 for its weekly frequency. The report prose says "times"; the source-chart convention retained by this dossier is days per week, not sessions. See the [category definition](../research/01_scope_and_metrics.md).

The original chart calls frequency the **average number of days per week**. It must not be described as sessions or number of uses. Older report summaries sometimes use looser language; the chart definition is used here.

The music row is a streaming-listening proxy in Comparison A. It is not enlarged to include soundtracks. In Comparison B, music, images, text and speech each include both standalone and embedded contact under the same rule. A painting shown in a vertical video belongs to the image component even though the host is video. No cross-format component union is measured here; video views or time cannot be reassigned to a component without coding. Earlier inclusive-music author scenarios are retained only in the separate author-interpretation archive and do not define either empirical comparison.
